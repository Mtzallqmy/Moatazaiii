# موصلات البحث العام الموسع

تستخدم المنصة ثلاثة موصلات قابلة للتشغيل المستقل. لا يحتاج أي موصل إلى جلسة زائر الموقع أو قائمة جهات اتصاله أو رقمه؛ تعمل جميعها بمفاتيح خادمية فقط.

| الموصل | المسار المتوقع | الغرض | حالة التفعيل |
|---|---|---|---|
| فهرس الرسائل العامة | `GET /search?q=&limit=` | اكتشاف قنوات عامة تظهر في فهرس الوسيط الحالي | يعمل حاليًا |
| خدمة TDLib | `GET /v1/public-chats/search?q=&limit=` | اقتراح كيانات تيليجرام العامة بالاسم أو المعرّف | يحتاج خدمة مستقلة واعتماد تيليجرام |
| الدليل متعدد اللغات | `GET /v1/directory/search?q=&limit=` | توسعة التغطية بحسب الفهرس المرخص ولغاته وبياناته | يحتاج مزود دليل مرخص |

يجب أن تعيد الخدمات شكلًا عامًا مثل `{ "results": [...] }`. يدعم المحول الحقول المباشرة (`title`, `username`, `description`, `language`, `subscriber_count`, `url`) أو شكل رسالة عامة (`text`, `date`, `chat: { title, username }`, `url`). لا يعرض المحول جسم الرسالة في البطاقة، بل يستخدمه داخليًا لتحديد «مطابقة ضمن إشارة عامة» ثم يتيح رابط الرسالة العامة.

تظهر حالة كل موصل في واجهة البحث: **متصل** أو **قيد التفعيل** أو **غير متاح**. لا توحي المنصة بتغطية عالمية كاملة عندما يكون موصل TDLib أو الدليل غير مفعل.
