# عقد وسيط البحث العام

تم التحقق من واجهة الوسيط المزوّد من المالك عبر وصف OpenAPI المنشور في 27 أغسطس 2026. لا تحتوي هذه الوثيقة على أي عنوان خاص أو مفتاح وصول.

| الخاصية | القيمة |
|---|---|
| اسم الخدمة | Telegram Public Search Proxy |
| الغرض المعلن | البحث في رسائل القنوات العامة ذات العنوان العام |
| فحص الجاهزية | `GET /health` |
| الاستعلام | `GET /search?q=<query>&limit=<1..50>` |
| التوثيق المدعوم | `X-API-Key` أو `Authorization` |
| حد طول الاستعلام | 1 إلى 100 محرف |
| شكل الاستجابة | كائن JSON مرن؛ يلزم تطبيع الحقول في خادم التطبيق |

يوفر هذا الوسيط نتائج مرتبطة برسائل قنوات عامة، وليس ضمانًا لفهرس عالمي لجميع الحسابات أو المجموعات أو القنوات. يعرض التطبيق هذه الحدود صراحة، ولا يشتق هوية شخص أو رقم هاتف من أي نتيجة.
